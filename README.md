# מערכת ניהול שיבוצים מעון הדס — גרסה 0.17.1

גרסת תיקון ממוקדת לתצוגת iPhone/Safari ולסמל מסך הבית.

## העלאה

1. אין להריץ SQL ב־Supabase.
2. החליפו ב־GitHub את כל קובצי גרסה `0.17.0` בקובצי `0.17.1`.
3. ודאו שבתיקיית `api` נשאר רק `api/index.js`.
4. בצעו Commit ו־Push והמתינו ל־`Ready` ב־Vercel.
5. פתחו `/health` ובדקו:
   - גרסת אתר: `0.17.1`
   - גרסת מסד: `0.12.0`

## רענון באייפון

פתחו פעם אחת: `https://hadas-garden.vercel.app/?v=0171`.

כדי לקבל את הסמל החדש במסך הבית, יש להסיר את הקיצור הישן ולהוסיף את האתר מחדש למסך הבית. iOS שומר את סמל הקיצור הישן במטמון גם לאחר עדכון האתר.

## מה תוקן

- הכפתורים בכותרת העליונה נשארים בתוך המסך.
- תוויות הניווט העליון אינן נחתכות.
- כותרות, טקסטים וכפתורי פעולה אינם בורחים לצדדים.
- טווח השבוע נשאר קבוע ונוח בשיבוצים ללא שטח ריק גדול.
- חלוניות הן מסך מלא בטלפון וכפתור הסגירה נשאר גלוי בזמן גלילה.
- סמל iOS הוחלף לקובץ מלא ללא שקיפות בפינות, כדי למנוע רקע לבן.
- כתובות Open Graph עודכנו לדומיין הפעיל `hadas-garden.vercel.app`.
