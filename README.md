# מערכת ניהול שיבוצים מעון הדס — גרסה 0.7.0

גרסה זו מתקנת את תצוגת המובייל שדווחה מהאתר הפעיל, מאיצה מעבר בין שבועות, מאפשרת יצירת אירוע בלחיצה על יום בלוח השנה ומשדרגת את מסך הגדרות התקינה.

## עדכון מהגרסה הפעילה 0.6.0

**אין להריץ SQL ב־Supabase.** גרסת מסד הנתונים נשארת `0.5.0`, וכל העובדות, הסיסמאות, השיבוצים והבקשות הקיימים נשמרים.

1. החלף ב־GitHub את כל קובצי 0.6.0 בקובצי 0.7.0.
2. ודא שבתיקיית `api` נמצא רק `index.js`.
3. בצע Commit ו־Push.
4. המתן עד ש־Vercel יציג `Ready`.
5. פתח `https://כתובת-האתר/health` וודא שכל הבדיקות ירוקות.
6. בטלפון סגור את לשונית האתר ופתח אותה מחדש. במחשב בצע `Ctrl+Shift+R` או `Cmd+Shift+R`.

אין צורך לשנות משתני סביבה. נשארים רק:

```text
SUPABASE_URL
SUPABASE_PUBLISHABLE_KEY
SUPABASE_SECRET_KEY
```

## מה חדש

### שיבוץ שבועי אמיתי בטלפון

במסכים עד `760px` הטבלה הרחבה אינה מוצגת עוד. במקומה יש שישה כרטיסי ימים מתקפלים:

- לחיצה על יום פותחת את שלוש הכיתות.
- בכל כיתה מוצגים מספר העובדות, מצב התקינה, שמות, תפקידים ושעות.
- עריכה, מחיקה, מציאת מחליפה והוספת עובדת נשארו זמינות.
- אין גלילה אופקית ואין חיתוך של עמודות.
- תצוגת המחשב נשארה טבלה שבועית מלאה.

### מעבר מהיר בין שבועות

- נוסף endpoint מצומצם שטוען רק את נתוני השבוע הדרושים.
- השבוע הקודם והבא נטענים מראש בזמן שהמערכת פנויה.
- שבועות שכבר נפתחו נשמרים בזיכרון זמני.
- בקשות כפולות לאותו שבוע מאוחדות במקום להישלח פעמיים.
- פעולות שיבוץ מרעננות רק את אזור השיבוצים ולא את כל המערכת.

### חלונות וטפסים במובייל

- חלונות בקשה, אירוע ותקינה מוגבלים לרוחב המסך ול־safe area של iPhone.
- כפתורי סוג בקשה מוצגים בשתי עמודות ברורות ללא חיתוך.
- תוקן באג שבו כפתור הרענון איבד את מבנה האייקון שלו והטקסט התנגש בכותרת.
- שדות, כפתורים וכותרות נשארים בתוך המסך גם ברוחב `360px`.

### לוח שנה

- לחיצה על שטח ריק בכל יום פותחת מיד יצירת אירוע עם התאריך הנבחר.
- אירוע קיים נשאר לחיץ ומציג את הפרטים המלאים.
- ניתן לבצע את אותה פעולה גם באמצעות Enter או רווח במקלדת.
- יום שניתן לבחור מקבל סימון `+` ומצב מיקוד ברור.

### הגדרות תקינה

- מוצגים שלושת חוקי הבסיס: צוות רגיל, צוות בסגירה וגננת/מובילה.
- נוסף איפוס מהיר לברירת המחדל של מעון הדס: `4/3`.
- נוספה תצוגה מקדימה של שעות הפעילות, תחילת חלון הסגירה ותדירות הבדיקות.
- ערכים לא הגיוניים מסומנים לפני שמירה.
- שינוי תקינה מנקה את מטמון השבוע ומרענן את הבדיקות מיד.
