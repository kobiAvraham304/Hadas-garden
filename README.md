# מערכת השיבוצים של מעון הדס

גרסה ראשונית עובדת המיועדת לפריסה ב־Vercel, עם Supabase לבסיס נתונים, התחברות ועדכונים בזמן אמת.

## חשוב מאוד לפני ההתקנה

המפתח הסודי של Supabase נמסר בתוך השיחה. לכן יש ליצור **Secret Key חדש** ב־Supabase, לבטל את המפתח הישן, ולהשתמש רק במפתח החדש בתוך משתני הסביבה של Vercel.

המפתח הסודי אינו נמצא בקבצי הפרויקט. אין להעלות אותו ל־GitHub ואין להכניס אותו ל־`app.js`, ל־HTML או לכל משתנה שמתחיל ב־`NEXT_PUBLIC`.

## שלב 1 — הכנת Supabase

1. היכנסו לפרויקט Supabase המתאים.
2. פתחו `SQL Editor`.
3. פתחו את הקובץ `supabase/schema.sql` מתוך הפרויקט.
4. העתיקו את כולו ל־SQL Editor ולחצו `Run`.
5. עברו אל `Authentication → Providers → Phone` והפעילו כניסה באמצעות טלפון.
6. עברו אל `Project Settings → API Keys`, צרו Secret Key חדש ובטלו את זה שנשלח בשיחה.

הסכמה יוצרת טבלאות עם קידומת `hadas_`, ולכן אינה אמורה להתערבב עם טבלאות של מערכת אופקים.

## שלב 2 — העלאה ל־GitHub

העלו את כל תיקיית הפרויקט למאגר GitHub חדש או לתיקייה ייעודית במאגר קיים. אין להעלות קובצי `.env` אמיתיים.

## שלב 3 — חיבור ל־Vercel

1. ב־Vercel בחרו `Add New → Project`.
2. בחרו את מאגר GitHub של מערכת הדס.
3. אין צורך לבחור Framework או פקודת Build.
4. הוסיפו ב־`Settings → Environment Variables` את המשתנים הבאים:

```text
SUPABASE_URL=https://tychhhhnndtlmygjxmxu.supabase.co
SUPABASE_PUBLISHABLE_KEY=sb_publishable_jOzEgw_U8rI-FR6FGh_ArA_t-LAitM_
SUPABASE_SECRET_KEY=<המפתח הסודי החדש שיצרתם>
SUPABASE_JWKS_URL=https://tychhhhnndtlmygjxmxu.supabase.co/auth/v1/.well-known/jwks.json
BOOTSTRAP_TOKEN=<קוד הקמה ארוך ופרטי לבחירתכם>
```

5. סמנו את המשתנים עבור Production, Preview ו־Development.
6. לחצו `Deploy`.

## שלב 4 — הקמה ראשונית

לאחר הפריסה פתחו:

```text
https://כתובת-האתר-שלכם.vercel.app/setup.html
```

הזינו:

- קוד ההקמה שהוגדר ב־`BOOTSTRAP_TOKEN`.
- מספר הטלפון של אילנית.
- מספר הטלפון של לינור.
- הסיסמה הראשונית המוצגת: `hadas`.

המערכת תיצור:

- אילנית — מנהלת מעון והרשאה מלאה.
- לינור אברהם — גננת ואחראית שיבוץ, עם שיוך ראשוני לכיתת אודם.

לאחר ההקמה ניתן להיכנס מעמוד הבית באמצעות מספר הטלפון והסיסמה `hadas`. בכניסה הראשונה כל משתמשת תחויב לבחור סיסמה אישית בת 8 תווים לפחות.

> הערה טכנית: Supabase דורש סיסמת Auth באורך מינימלי של 6 תווים. המערכת מתאימה מאחורי הקלעים את הסיסמה הראשונית הקצרה `hadas`, בלי לשנות את מה שהעובדות מקלידות.

## ניהול עובדות

אילנית ולינור יכולות להיכנס למסך `עובדות` ולבצע:

- הוספת עובדת חדשה.
- שינוי שם, טלפון, תפקיד והרשאה.
- שיוך לכיתה קבועה.
- הגדרת יכולת הובלה.
- הגדרת שעות שבועיות ושעות רגילות.
- הגדרת יום חופשי קבוע או משתנה.
- הוספת עדיפות, הימנעות או איסור שיבוץ בכיתה.
- כתיבת הערה ניהולית שרק אילנית ולינור רואות.
- איפוס סיסמה ל־`hadas`.
- השבתת עובדת תוך שמירת היסטוריית השיבוצים.

## חוקי השיבוץ בגרסה 0.1.0

- שעות הפעילות: 07:30–15:30.
- יעד בסיסי: 4 נשות צוות בכל כיתה, כולל גננת.
- אם אין גננת, ניתן לשבץ מובילה.
- נדרשות לפחות 3 נשות צוות שמסיימות בשעת הסגירה.
- המערכת מתריעה על יום חופשי קבוע, חוסר צוות, חוסר בגננת/מובילה והגבלת כיתה.
- המערכת חוסמת חפיפה של אותה עובדת בשני שיבוצים באותן שעות.
- חישוב כוח אדם לפי מספר הילדים יתווסף בגרסה עתידית.

## עדכונים בזמן אמת

שינויים בשיבוצים, עובדות, בקשות ונוכחות נשלחים דרך Supabase Realtime. כאשר לינור או אילנית משנות שיבוץ, משתמשות מחוברות מקבלות את הנתונים המעודכנים ללא רענון ידני.

## מבנה מרכזי

```text
index.html                 המערכת הראשית
app.js                     התחברות, שיבוצים, בקשות, נוכחות ו-Realtime
styles.css                 עיצוב רספונסיבי בעברית
setup.html / setup.js      הקמה ראשונית של לינור ואילנית
api/                       פעולות שרת מאובטחות ב-Vercel
supabase/schema.sql        טבלאות, הרשאות, RLS, Realtime ו-Audit
vercel.json                הגדרות אבטחה לפריסה
```

## פתרון תקלות נפוצות

### ההתחברות לפי טלפון נכשלת

ודאו ש־Phone provider מופעל ב־Supabase ושמספר הטלפון הוזן בפורמט ישראלי תקין.

### מסך ההקמה אומר שהטבלאות אינן קיימות

יש להריץ את `supabase/schema.sql` במלואו ב־SQL Editor.

### יצירת עובדת נכשלת

בדקו שהוגדר ב־Vercel Secret Key חדש ונכון, ושבוצע Redeploy לאחר הוספת משתני הסביבה.

### העדכונים אינם מופיעים בזמן אמת

ודאו שהסקריפט הסתיים ללא שגיאה ושהטבלאות `hadas_profiles`, `hadas_shifts`, `hadas_attendance`, `hadas_requests` ו־`hadas_schedule_acknowledgements` מופיעות בפרסום `supabase_realtime`.
