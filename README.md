# מערכת ניהול שיבוצים מעון הדס — גרסה 0.17.0

גרסה זו מבצעת שינוי מבני עמוק בממשק הסלולר, מאחדת את מנוע התאמת העובדים ומחליפה את מנגנון יצוא התמונות במנוע Canvas ייעודי וברור.

## העלאה מגרסה 0.16.0

1. אין להריץ SQL ב־Supabase — סכמת המסד נשארת `0.12.0`.
2. החליפו ב־GitHub את כל קובצי גרסה `0.16.0` בקובצי `0.17.0`.
3. ודאו שבתיקיית `api` נשאר רק `api/index.js`.
4. בצעו Commit ו־Push והמתינו ל־`Ready` ב־Vercel.
5. פתחו `/health` ובדקו:
   - גרסת אתר: `0.17.0`
   - גרסת מסד: `0.12.0`
6. באייפון סגרו את לשונית האתר ופתחו מחדש. קובצי העיצוב והקוד כוללים חותמת `v=017`, ו־Vercel מוגדר לא לשמור את קובצי הממשק במטמון ישן.

## משתני Vercel

נדרשים רק:

- `SUPABASE_URL`
- `SUPABASE_PUBLISHABLE_KEY`
- `SUPABASE_SECRET_KEY`

## עיקרי הגרסה

- ניווט סלולר קבוע בחלק העליון, הרחק מסרגל הכלים של Safari.
- חלוניות עריכה כמסכי עבודה מלאים, עם כפתור סגירה וכפתורי שמירה דביקים.
- כרטיסים וכפתורים קומפקטיים ללא תזוזה אופקית.
- לוח שנה שמותאם לרוחב הטלפון ללא גלילה לצדדים.
- מנוע התאמה אחד להוספה, החלפה ותפעול יומי.
- הצגת הסיבות לכך שעובדים מסוימים לא הופיעו ברשימת ההמלצות.
- יצוא שבוע כתמונה אחת לרוחב.
- יצוא חודש כחבילת תמונות שבועיות ברורות, במקום תמונה חודשית ארוכה ובלתי קריאה.
- PDF שבועי בנוף באמצעות אותה תמונת שיבוץ ברורה.
