# מערכת ניהול שיבוצים מעון הדס — גרסה 0.8.0

גרסה זו מתמקדת בתיקון הבעיות שדווחו באתר הפעיל: הצפת מאות שגיאות תקינה, פתיחה אוטומטית של ימים בשיבוץ השבועי, כותרת שבוע שנעלמת בגלילה, לוח שנה שנתקע, ייצוא לא ברור ושפה שפנתה רק לעובדות.

## עדכון מהגרסה הפעילה 0.7.0

**אין להריץ SQL ב־Supabase.** גרסת מסד הנתונים נשארת `0.5.0`, וכל העובדים, הסיסמאות, השיבוצים, הבקשות והאירועים הקיימים נשמרים.

1. החלף ב־GitHub את כל קובצי 0.7.0 בקובצי 0.8.0.
2. ודא שבתיקיית `api` נשאר רק `api/index.js`.
3. בצע Commit ו־Push.
4. המתן עד ש־Vercel יציג `Ready`.
5. פתח `https://כתובת-האתר/health` וודא שכל הבדיקות ירוקות.
6. באייפון סגור את לשונית האתר ופתח אותה מחדש. במחשב בצע רענון מלא.

אין צורך להוסיף משתני סביבה. נשארים רק:

```text
SUPABASE_URL
SUPABASE_PUBLISHABLE_KEY
SUPABASE_SECRET_KEY
```

## השיפורים העיקריים

### שגיאות והתראות תקינה

- במקום שגיאה חדשה לכל חצי שעה, המערכת מאחדת את כל מקטעי התקלה לפי יום וכיתה.
- בשבוע ריק יוצגו לכל היותר מוקדי התקינה הרלוונטיים, ולא מאות שורות חוזרות.
- לחיצה על מונה השגיאות פותחת את הרשימה.
- לחיצה על שגיאה עוברת לתאריך ולכיתה שדורשים תיקון ומדגישה אותם.
- לחיצה על התראת שעות עוברת לכרטיס העובד המתאים.
- גם בחלון שלפני פרסום השיבוץ השגיאות לחיצות.

### שיבוץ שבועי בטלפון

- אף יום אינו נפתח אוטומטית.
- ניתן לפתוח יום אחד בלבד בכל פעם.
- כותרת השבוע והחצים נשארים קבועים בראש המסך בזמן גלילה.
- תצוגות שבוע מלא, לפי יום והשיבוץ שלי נשארו זמינות.
- אין גלילה אופקית ואין חיתוך של כרטיסי השיבוץ.

### שמירה, תמונה ו־PDF

- `📷 שבוע כתמונה` יוצר תמונה אחת לרוחב של כל השבוע.
- `🗓️ חודש כתמונה` זמין ללינור ולאילנית ומכין את כל שבועות החודש.
- באייפון נפתח תפריט השיתוף של המכשיר, שממנו ניתן לבחור שמירה לתמונות; במחשב הקובץ יורד ישירות.
- אם שיתוף הקובץ אינו זמין, המערכת עוברת אוטומטית להורדה רגילה.
- גודל התמונה החודשית מותאם אוטומטית למגבלות הדפדפן בטלפון.
- הדפסה/PDF משתמשים בתבנית שבועית אחת, ברורה ובפורמט A4 לרוחב.

### לוח שנה ומהירות

- מעבר חודש מעדכן את הכותרת מיד ומציג נתונים מהמטמון כאשר הם כבר נטענו.
- בקשות ישנות אינן יכולות לדרוס חודש חדש שנבחר.
- החודש הקודם והבא נטענים מראש כשהמערכת פנויה.
- לחיצה על יום פותחת יצירת אירוע עם התאריך שנבחר.
- מעבר שבוע משתמש במטמון ומטעין מראש את השבוע הסמוך.
- במעבר בין מסכים מוצג רק המסך הפעיל, בלי לבנות מחדש את כל הממשק.

### שפה

כל הניסוחים הכלליים שונו ל־`עובדים`, `עובד`, `מחליף/ה`, `גננת/גנן` ו־`מוביל/ה`. שמות ותפקידים אישיים נשארים כפי שהוגדרו בכרטיס העובד.
