# מערכת ניהול שיבוצים מעון הדס — גרסה 0.11.0

גרסת המשך לגרסה 0.10.0, עם התאמה לשעות יום שישי, שיוך עובדים מתקדם, הרשאות צפייה לפי תפקיד ומסך תפעול יומי.

## עדכון מגרסה 0.10.0

1. ב־Supabase פתחו **SQL Editor**.
2. הריצו פעם אחת בלבד את `supabase/update-v0.11.0.sql`.
3. אין להריץ מחדש את `schema.sql` ואין להריץ שוב עדכונים ישנים.
4. החליפו ב־GitHub את קובצי גרסה 0.10.0 בכל קובצי 0.11.0.
5. ודאו שבתיקיית `api` קיים רק `api/index.js`.
6. לאחר ש־Vercel מציג `Ready`, פתחו `/health` וודאו שגרסת האתר והמסד היא `0.11.0`.

אין צורך לשנות משתני סביבה ב־Vercel.

## עיקרי הגרסה

- יום שישי מוגדר עד 12:00 בכל בדיקות השיבוץ והתקינה.
- אופן שיוך: כיתה קבועה, רוטציה בין כיתות או משלימ/ת מקום.
- משלימ/ת מקום יכול/ה להיות מסומן/ת ביום קבוע כ־`לפי צורך`.
- סייעת מובילה רואה את השיבוץ של הכיתה הקבועה בלבד.
- סייעת/סייע רגילים רואים רק את השיבוץ האישי.
- כרטיס העובד, שעות, אילוצים והערות ניהוליות מוצגים רק למנהלת המעון ולאחראית השיבוץ.
- בקשת חופשה של יותר מיומיים רצופים מציגה תזכורת לטופס ידני.
- בבקשת חופשה ניתן לציין אם אפשר לשבץ ביום החופשי הקבוע לפי צורך.
- מסך ניהול העובדים כולל סיכומים לחיצים לפי תפקיד ואופן שיוך.
- נוסף מסך **תפעול יומי** לדיווח מחלה, היעדרות, איחור, שחרור מוקדם או שינוי אחר.
- מסך התפעול מציע מחליפים פנויים והעברות חירום בין כיתות, תוך בדיקת תקינה, שעות, אילוצים והעדפות.
- לאחר שמירת דיווח היעדרות, המערכת פותחת מיד את אפשרויות הכיסוי הבטוחות.
- הגדרות התקינה מציגות בנפרד א׳–ה׳ ויום שישי, תקן רגיל, תקן סגירה וחובת אחראי/ת כיתה.
