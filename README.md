# מערכת ניהול שיבוצים מעון הדס — גרסה 0.14.0

גרסת עיצוב ונגישות המתמקדת במיתוג האתר, שיתוף הקישור ובמסך ניהול העובדים.

## העלאה

1. אין להריץ SQL ב־Supabase.
2. החליפו ב־GitHub את קובצי גרסה 0.13.0 בקובצי גרסה 0.14.0.
3. ודאו שבתיקיית `api` נשאר רק `api/index.js`.
4. בצעו Commit ו־Push והמתינו ל־`Ready` ב־Vercel.
5. פתחו `/health` וודאו:
   - גרסת אתר `0.14.0`
   - גרסת מסד נתונים `0.12.0`

## שיתוף ב־WhatsApp

הגרסה כוללת תמונת שיתוף `og-image.png` ותגיות Open Graph. WhatsApp עשויה להציג תצוגה ישנה ששמרה במטמון. במקרה כזה משתפים פעם אחת את הקישור עם פרמטר חדש, לדוגמה `?v=014`, ולאחר מכן התצוגה החדשה נטענת.
