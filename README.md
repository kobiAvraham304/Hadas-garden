# מערכת השיבוצים של מעון הדס — גרסה 0.4.1

גרסת תיקון להתקנה הראשונית. היא מתקנת את שגיאת Supabase:

```text
record "new" has no field "updated_at"
```

השגיאה נגרמה מכך שטבלת `hadas_classes` מגרסה ישנה לא כללה את העמודה `updated_at`, אך נשאר עליה Trigger שניסה לעדכן אותה.

## מה לעשות עכשיו — שלושה שלבים בלבד

### 1. להריץ את קובץ ה־SQL החדש

1. היכנס ל־Supabase → **SQL Editor**.
2. מחק את הקוד הישן מהעורך.
3. פתח מהגרסה החדשה את `supabase/schema.sql` והעתק את כולו.
4. לחץ **Run**.
5. אם מופיע החלון `Potential issues detected`, בחר **Run without RLS**.

הבחירה הזאת נכונה מפני שהקובץ עצמו מפעיל RLS בסוף ההרצה ומגדיר את ההרשאות במדויק.

הקובץ מנקה רק טבלאות ופונקציות ששמן מתחיל ב־`hadas_`, ואז בונה אותן מחדש. הוא לא נוגע במערכת אופקים או בטבלאות אחרות. מאחר שהמערכת עדיין בהקמה ולא הוזנו אליה נתונים, זו הדרך היציבה והפשוטה ביותר לתקן את ההתקנה החלקית.

### 2. להעלות את גרסה 0.4.1 ל־GitHub

החלף את קובצי גרסה 0.4.0 בקובצי גרסה 0.4.1, בצע Commit ו־Push, והמתן שב־Vercel יופיע `Ready`.

ב־Vercel נדרשים רק:

```text
SUPABASE_URL
SUPABASE_PUBLISHABLE_KEY
SUPABASE_SECRET_KEY
```

### 3. לבדוק ולהתחבר

פתח:

```text
https://כתובת-האתר/health
```

כאשר הכול ירוק, חזור למסך הכניסה.

| שם | טלפון | הרשאה |
|---|---|---|
| אילנית זאדייב | 0544594513 | מנהלת מעון |
| לינור אברהם | 0542521780 | גננת ואחראית שיבוץ |

הסיסמה הראשונית: `hadas`

בכניסה הראשונה תתבקש החלפת סיסמה.

## מה כולל האתר

- התחברות בטלפון וסיסמה, ללא מייל וללא SMS.
- ניהול עובדות והרשאות על ידי אילנית ולינור.
- שיבוץ שבועי לפי שעות, כולל יום מפוצל ומעבר בין כיתות.
- תצוגות שבוע, יום והשיבוץ האישי.
- בדיקות כוח אדם, גננת או מובילה, חפיפות ואילוצי כיתה.
- הצעת מחליפות לפי זמינות והתאמה.
- בקשות חופשה, מחלה, שעות והחלפות באישור.
- נוכחות, הודעות, משימות, לוח שנה ומסמכים.
- עדכונים חיים באמצעות Supabase Realtime.
- התאמה למחשב ולסלולר, הדפסה ל־PDF ושמירה כתמונה.
