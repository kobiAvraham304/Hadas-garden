# מערכת ניהול שיבוצים מעון הדס — גרסה 0.10.0

גרסה זו מוסיפה הפרדת הרשאות לצפייה בשיבוצים, תהליך החלפה דו־שלבי, מרכז עדכונים אישי, טווחי חופשה ומחלה וצירוף אישור מחלה פרטי.

## עדכון מהגרסה הפעילה 0.9.0

בגרסה זו יש עדכון חד־פעמי ל־Supabase.

1. היכנס ל־Supabase → SQL Editor.
2. פתח את `supabase/update-v0.10.0.sql` והריץ את כל הקובץ פעם אחת.
3. אין להריץ מחדש את `schema.sql` על המערכת הפעילה.
4. החלף ב־GitHub את כל קובצי 0.9.0 בקובצי 0.10.0.
5. ודא שבתיקיית `api` נשאר רק `api/index.js`.
6. בצע Commit ו־Push והמתן ל־`Ready` ב־Vercel.
7. פתח `https://כתובת-האתר/health` וודא שכל הבדיקות ירוקות ושגרסת מסד הנתונים היא `0.10.0`.
8. באייפון סגור את לשונית האתר ופתח אותה מחדש. במחשב בצע רענון מלא.

אין משתני סביבה חדשים. נשארים רק:

```text
SUPABASE_URL
SUPABASE_PUBLISHABLE_KEY
SUPABASE_SECRET_KEY
```

## הרשאות צפייה בשיבוצים

- גננת/גנן, אחות, מנהלת מעון ומזכירה רואים את השיבוץ המלא.
- לינור ואילנית ממשיכות לראות ולנהל את כל השיבוצים מכוח הרשאת הניהול שלהן.
- סייעת, סייע, סייעת מובילה ועובדים אחרים רואים רק את השיבוץ האישי שלהם.
- ההגבלה נאכפת גם בשרת: נתוני שיבוץ של עובדים אחרים אינם נשלחים למשתמש שאין לו הרשאה מלאה.

## בקשת החלפה

1. העובד בוחר תאריך בלבד.
2. המערכת מציגה רק עובדים שנמצאים ביום חופשי באותו יום, אינם משובצים, פעילים וזמינים.
3. העובד שנבחר מקבל עדכון אישי ורואה את הבקשה במסך הראשי ובמסך הבקשות.
4. העובד שנבחר מאשר או דוחה.
5. רק לאחר אישורו הבקשה עוברת לטיפול אילנית או לינור.
6. לאחר אישור והזרמה, כל מקטעי השיבוץ של המבקש באותו יום מועברים לעובד המחליף בטיוטת השיבוץ וממתינים לפרסום.

## עדכונים והתראות

- נוסף כפתור `עדכונים` עם מונה של פריטים שלא נקראו.
- מרכז העדכונים מציג רק עדכונים הקשורים לעובד המחובר.
- המרכז כולל בקשות החלפה, החלטות בבקשות, פרסום שיבוץ ועדכונים תפעוליים.
- פריט שדורש פעולה מסומן בבירור ופותח את המסך הרלוונטי.
- ניתן לסמן עדכון בודד או את כל העדכונים כנקראו.

## חופשה, מחלה ואישור מחלה

- בקשת חופשה תומכת בתאריך התחלה ובתאריך סיום.
- בקשת מחלה תומכת בתאריך התחלה ובתאריך סיום.
- בבקשת מחלה ניתן לצרף PDF או תמונה מסוג JPG, PNG או WEBP עד 3MB.
- האישור נשמר ב־Supabase Storage בדלי פרטי.
- רק העובד שהגיש את הבקשה ואילנית/לינור יכולים לפתוח את האישור באמצעות קישור זמני.
- אם שמירת הבקשה נכשלת לאחר העלאת קובץ, המערכת מנקה את הקובץ כדי למנוע קבצים מיותרים.

## שינויים נוספים

- האפשרות `אחר` הוסרה ממסך הבקשה ומ־API הבקשות.
- החלפות, חופשות ומחלות ממשיכות להיכנס לטיוטת השיבוץ ורק לאחר מכן מתפרסמות לצוות.
- נשארה פונקציית Vercel אחת בלבד, ולכן הגרסה מתאימה לתוכנית Hobby.
- מספר הגרסה מוצג בממשק כ־`v0.10.0`.
