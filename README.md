# מערכת ניהול שיבוצים מעון הדס — גרסה 0.6.0

גרסת עיצוב גדולה למערכת הפעילה, עם שפה חזותית חדשה שמתאימה למעון: נעימה, צבעונית במידה, מקצועית ונוחה לגננות, סייעות וצוות פרא־רפואי. הגרסה כוללת גם שיפור משמעותי של השימוש בטלפון, מסננים חדשים ותצוגת חופשות והיעדרויות בתוך מסך השיבוצים.

## עדכון מהגרסה 0.5.0

**אין צורך להריץ SQL ב־Supabase.** מבנה מסד הנתונים נשאר בגרסה `0.5.0`, וכל הנתונים והחשבונות הקיימים נשמרים.

1. החלף ב־GitHub את כל קובצי הגרסה הקודמת בקובצי 0.6.0.
2. ודא שבתיקיית `api` נמצא רק הקובץ `index.js`.
3. בצע Commit ו־Push.
4. המתן עד ש־Vercel יציג `Ready`.
5. פתח `https://כתובת-האתר/health` וודא שכל הבדיקות ירוקות.
6. בצע רענון מלא בדפדפן כדי למחוק עיצוב ישן מהמטמון.

אין צורך לשנות משתני סביבה. נשארים רק:

```text
SUPABASE_URL
SUPABASE_PUBLISHABLE_KEY
SUPABASE_SECRET_KEY
```

## עיקרי הגרסה

### שפה חזותית חדשה

- הוחלף העיצוב הירוק־אחיד בפלטה מאוזנת של סגול, תכלת, קורל, צהוב ומנטה.
- נוספו איורים עדינים של שמש, עננים ופרחים, בלי להפוך את המערכת לילדותית או עמוסה.
- לכל סוג מידע יש צבע עקבי: שיבוצים, בקשות, חופשות, משימות, הודעות וכיתות.
- כרטיסים, חלונות, כותרות, כפתורים, מצבי ריחוף ומצבי לחיצה עוצבו מחדש.
- נוספו הנפשות עדינות, עם תמיכה בהגדרת מערכת להפחתת תנועה.

### התאמה אמיתית לטלפון

- ניווט תחתון חדש עם חמש פעולות מרכזיות.
- מסכים משניים נמצאים בתפריט “עוד” שנפתח מלמטה.
- כפתורים גדולים ונוחים למגע.
- טפסים וחלונות נפתחים כגיליון תחתון בטלפון.
- אזורי פעולות מסתדרים מחדש בלי חפיפות ובלי גלילה אופקית של כל הדף.
- תצוגות נבדקו ברוחב 390 ו־360 פיקסלים, נוסף על תצוגת מחשב.

### מסננים וחיפוש

- מסנני הבקשות וניהול העובדות הוחלפו בכפתורי בחירה חזותיים.
- מצב הבחירה מודגש בבירור.
- החיפוש והמסננים מסתדרים מחדש במסכים צרים.
- אפשר לעבור במהירות בין מצבי בקשה, סוגי תפקידים ומצב עובדת.

### חופשות והיעדרויות בשיבוץ

בתחתית מסך השיבוצים נוסף אזור חדש המציג לכל יום:

- מי בחופשה.
- מי ביום חופשי.
- מי במחלה מאושרת.
- מספר ההיעדרויות באותו יום ובכל השבוע.

בתצוגת “לפי יום” מוצג רק היום שנבחר. הסיבה האישית לבקשה אינה נחשפת לעובדות אחרות.

### שיפורי מסכים

- מסך ראשי חדש עם תמונת מצב צבעונית ופעולות מהירות.
- כרטיסי כיתות ברורים יותר, כולל שמות, תפקידים ושעות קריאות.
- מסך שיבוצים נקי יותר במחשב ובטלפון.
- מסך בקשות עם כרטיסים, שלבי טיפול וכפתורי פעולה ברורים.
- הודעות ומשימות קיבלו היררכיה חזותית חדשה.
- ניהול עובדות כולל כרטיסים צבעוניים לפי תחום, סטטוס והרשאה.
- לוח השנה עוצב מחדש עם צבע שונה לכל סוג אירוע.

### קוד וביצועים

- פונקציית Vercel אחת בלבד, בהתאם לתוכנית Hobby.
- אין מודולים או מסכים מיותרים שהוסרו בגרסאות קודמות.
- רענון חי ממשיך לפעול דרך Supabase Realtime.
- לא נוספו שאילתות כבדות או טבלאות חדשות.
- רשימת החופשות נבנית בשרת מתוך הנתונים הקיימים ונשלחת ללא נימוקים פרטיים.
- נשמרו הגנות הסשן, CSRF והפרדת הרשאות.
