# מערכת ניהול שיבוצים מעון הדס — גרסה 0.12.0

גרסת קפיצת מדרגה המחברת בין נוכחות בפועל, תפעול יומי ושיבוץ, ומשפרת את דרך העבודה של מנהלת המעון ואחראית השיבוץ.

## עדכון מגרסה 0.11.0

1. ב־Supabase פתחו **SQL Editor**.
2. הריצו פעם אחת בלבד את `supabase/update-v0.12.0.sql`.
3. אין להריץ מחדש את `schema.sql` ואין להריץ שוב עדכונים ישנים.
4. החליפו ב־GitHub את קובצי גרסה 0.11.0 בכל קובצי 0.12.0.
5. ודאו שבתיקיית `api` קיים רק `api/index.js`.
6. בצעו Commit ו־Push והמתינו ל־`Ready` ב־Vercel.
7. פתחו `/health` וודאו שגרסת האתר והמסד היא `0.12.0`.

אין צורך לשנות משתני סביבה ב־Vercel.

## עיקרי הגרסה

### נוכחות ותפעול יומי

- מנהלת המעון ואחראית השיבוץ יכולות לדווח נוכחות ישירות מתוך תפעול יומי.
- מחלה, היעדרות, איחור או שחרור מוקדם יוצרים אוטומטית אירוע תפעולי בשעות החסרות.
- שינוי נוכחות בחזרה ל־„נכח” מנקה אירוע אוטומטי שכבר אינו רלוונטי.
- ניתן לסמן בבת אחת את כל העובדים שטרם עודכנו כנוכחים.
- תפעול יומי מציג: דורש טיפול, טרם דווחה נוכחות וטופל.
- ניתן לערוך דיווח, למחוק דיווח ידני, לסגור אירוע ללא כיסוי או לפתוח אותו מחדש.
- הצעות הכיסוי מדורגות לפי זמינות, כיתה קבועה, רוטציה, השלמה, העדפות, שעות ומקסימום שבועי.
- העברת חירום מכיתה אחרת מוצעת רק אם כיתת המקור נשארת בתקינה ועם אחראי/ת כיתה.
- אם חסרה הגננת או המובילה היחידה, יוצעו רק עובדים שמורשים להוביל את הכיתה.

### שיבוצים

- בעת הוספה או עריכת שיבוץ מוצגים תחילה העובדים המתאימים ביותר.
- העובדים מדורגים לפי הכרטיס האישי, ימי העבודה, השעות, שיוך לכיתה, אילוצים והיקף השעות.
- עדיין ניתן לבחור עובד אחר מרשימת כלל העובדים ולראות את החריגה לפני הפרסום.
- שגיאות התקינה מוצגות ככרטיסי פעולה עם דרך תיקון: הצעת עובד, הוספת שיבוץ, פתיחת כרטיס עובד או הגדרות תקינה.
- שינוי בשבוע שכבר פורסם פותח חלונית ברורה המאפשרת לפרסם את השינוי בפועל או להמשיך לערוך.

### מסך ראשי

- קוביית בקשות ממתינות ניתנת ללחיצה ופותחת את מסך הבקשות.
- קוביית הודעות שלא נקראו ניתנת ללחיצה ופותחת את ההודעות.
- קוביית העדכונים פותחת את מרכז ההתראות האישי.

### מהירות ויציבות

- תפעול יומי נטען בנפרד ואינו מרענן את כל המערכת.
- נשמר מטמון יומי קצר ומונעות בקשות כפולות לאותו תאריך.
- עדכון נוכחות מרענן רק את המסכים הרלוונטיים.
- נתוני Realtime של נוכחות ותפעול מעדכנים זה את זה.
- הצעות שיבוץ נשמרות במטמון קצר ומחושבות מחדש רק כשמשתנים התאריך, הכיתה, השעות או התפקיד.
- נשארה פונקציית Vercel אחת בלבד והתאמה מלאה לתוכנית Hobby.
