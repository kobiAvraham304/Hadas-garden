# מערכת השיבוצים של מעון הדס — גרסה 0.4.3

גרסה זו מתקנת את חסימת הפריסה ב־Vercel Hobby:

```text
No more than 12 Serverless Functions can be added to a Deployment on the Hobby plan
```

בגרסאות הקודמות כל קובץ API הפך לפונקציית שרת נפרדת. כעת כל 17 נתיבי ה־API פועלים דרך **פונקציית Serverless אחת**, בלי לבטל אף מסך או יכולת.

## מה לעשות עכשיו

### 1. Supabase

אין שינוי בבסיס הנתונים לעומת 0.4.1.

- אם קובץ ה־SQL של 0.4.1 כבר הסתיים ב־`Success` — **לא להריץ SQL שוב**.
- אם עדיין לא הייתה הרצה מוצלחת — הרץ פעם אחת את `supabase/schema.sql` המצורף ובחלון האזהרה בחר `Run without RLS`. הקובץ מפעיל RLS בעצמו בסיום.

### 2. GitHub ו־Vercel

1. החלף ב־GitHub את כל קובצי הגרסה הקודמת בקובצי 0.4.3.
2. בצע Commit ו־Push.
3. המתן שב־Vercel יופיע `Ready`.

לא צריך לעבור לתוכנית Pro ולא צריך לשנות הגדרה ב־Vercel.

נדרשים רק שלושת משתני הסביבה הקיימים:

```text
SUPABASE_URL
SUPABASE_PUBLISHABLE_KEY
SUPABASE_SECRET_KEY
```

### 3. בדיקה והתחברות

פתח:

```text
https://כתובת-האתר/health
```

לאחר שהכול ירוק אפשר להתחבר:

| שם | טלפון | הרשאה |
|---|---|---|
| אילנית זאדייב | 0544594513 | מנהלת מעון |
| לינור אברהם | 0542521780 | גננת ואחראית שיבוץ |

הסיסמה הראשונית היא `hadas`, ובכניסה הראשונה תידרש החלפת סיסמה.

## מה נשאר פעיל

- כניסה בטלפון וסיסמה ללא מייל וללא SMS.
- ניהול עובדות והרשאות.
- שיבוץ שבועי לפי מקטעי שעות ופיצול יום.
- תקינת ארבע נשות צוות ושלוש בסגירה.
- גננת או מובילה בכל כיתה.
- מנוע הצעת מחליפות.
- בקשות, החלפות, חופשות ומחלות.
- נוכחות בפועל.
- הודעות, משימות, לוח שנה ומסמכים.
- Supabase Realtime.
- תצוגות מחשב וסלולר, PDF ותמונה.
