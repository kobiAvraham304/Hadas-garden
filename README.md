# מערכת ניהול שיבוצים מעון הדס — גרסה 0.13.0

גרסת ליטוש, נגישות ובהירות למערכת הקיימת. הגרסה משפרת את מסך הכניסה, הגדרות התקינה, מערכת השגיאות, הצעות העובדים וניהול העובדים, ללא שינוי במבנה בסיס הנתונים.

## עדכון מגרסה 0.12.0

1. **אין להריץ SQL ב־Supabase.** בסיס הנתונים נשאר בגרסה `0.12.0`.
2. החליפו ב־GitHub את כל קובצי גרסה 0.12.0 בקובצי 0.13.0.
3. ודאו שבתיקיית `api` קיים רק `api/index.js`.
4. בצעו Commit ו־Push והמתינו ל־`Ready` ב־Vercel.
5. פתחו `/health` וודאו:
   - גרסת אתר: `0.13.0`
   - גרסת מסד נתונים: `0.12.0`
6. בטלפון סגרו את לשונית האתר ופתחו אותה מחדש אם עדיין מוצג העיצוב הישן.

אין צורך לשנות משתני סביבה ב־Vercel.

## עיקרי הגרסה

### מסך כניסה

- הוסרה לחלוטין הצגת „בדיקת חיבור”.
- נוספה הנחיה ברורה: לאיפוס סיסמה יש לפנות לאחראית השיבוצים או למנהלת המעון.
- נוסף קרדיט קטן: `פיתוח: קובי אברהם`.
- נוסף סמל מערכת חדש המוצג במסך הכניסה, בכותרת האתר, בלשונית הדפדפן ובהוספה למסך הבית.

### הגדרות תקינה

- מסך ההגדרות פושט ונבנה מחדש.
- שלושה כללים מוכנים: תקן הדס `4/3`, תקן מלא `4/4` ותקן מצומצם `3/3`.
- כפתורי `+` ו־`−` גדולים לשינוי מספר העובדים.
- שעות א׳–ה׳ ויום שישי מוצגות בנפרד.
- הגדרות מתקדמות נשמרות באזור נפתח כדי לא להעמיס.
- תצוגה מקדימה מסבירה מיד מה המשמעות של ההגדרה.

### בדיקות תקינות ושגיאות

- השגיאות אינן פתוחות אוטומטית.
- כפתור „בדיקות תקינות” מציג רק את מספר הנקודות לבדיקה.
- לחיצה פותחת כרטיסים ברורים עם יום, כיתה, שעות ופעולת תיקון.
- תוצאות בדיקת השיבוץ נשמרות בזיכרון ומחושבות מחדש רק לאחר שינוי רלוונטי.

### הצעת עובד מתאים

- ציון ההתאמה מוצג תמיד בסולם ברור של `1–100`.
- נוסף פס צבעוני קטן שממחיש התאמה נמוכה, בינונית או גבוהה.
- לצד הציון מוצגות הסיבות להתאמה והאזהרות הרלוונטיות.

### ניהול עובדים

- מנהלת המעון ואחראית השיבוצים רואות מי כבר התחבר למערכת.
- מוצג סיכום כמה עובדים נרשמו וכמה עדיין לא נכנסו.
- בכרטיס עובד מוצג סטטוס „נרשם” או „טרם נרשם”, ובמידת האפשר מועד הכניסה האחרון.
- מידע זה אינו נשלח לעובדים רגילים.

### תפקיד באותו יום

התפקידים בשיבוץ נוסחו מחדש בצורה ברורה:

- גננת/גנן — אחראי/ת כיתה.
- מוביל/ת כיתה — אחראי/ת כיתה.
- צוות כיתה.
- מילוי מקום / החלפה.

בעת בחירת עובד המערכת מציעה אוטומטית את תפקיד היום המתאים לפי כרטיס העובד, ועדיין מאפשרת לשנות אותו.
