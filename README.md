# מערכת ניהול שיבוצים מעון הדס — גרסה 0.24.0

מערכת ניהול שבועית למעון הדס: שיבוצים, שיבוץ אוטומטי, זמינות צוות, תפעול יומי, בקשות, התראות ולוח שנה.

## שדרוג מ־0.23.0

1. מריצים פעם אחת את `supabase/update-v0.24.0.sql` בפרויקט Supabase של הדס.
2. לא מריצים מחדש את `supabase/schema.sql` על מערכת קיימת.
3. מעלים את קובצי 0.24.0 לענף `main` וממתינים ל־Vercel `Ready`.
4. ב־`/health` מוודאים: אתר `0.24.0`, מסד `0.24.0` ושני החשבונות הראשוניים קיימים.

לא נוספו משתני סביבה חדשים. המערכת עדיין דורשת רק:

- `SUPABASE_URL`
- `SUPABASE_PUBLISHABLE_KEY`
- `SUPABASE_SECRET_KEY`

## עיקרי הגרסה

- טבלת שבוע צפופה יותר וזמינות מלאה, כולל ימי חופש קבועים.
- מנוע שיבוץ אוטומטי עם משמרות מעשיות, הסבר לחוסרים והגנה מתוצאה שהתיישנה.
- החלה אטומית של שיבוץ אוטומטי ללא מצב ביניים של שבוע מחוק.
- תפעול יומי טבלאי שמבוסס על השיבוץ העדכני ומאפשר דיווח ישיר על עובד.
- לוח שנה שמסביר את מקור החופשה ומונע תוויות חסרות.
- מסך התראות עם סינון ברור וניקוי פעולות שכבר הושלמו.
- הגנות על מחיקת שיבוץ שיש לו דיווח או בקשה פתוחה.
