# מערכת ניהול שיבוצים מעון הדס — גרסה 0.5.0

גרסה חדשה ומקיפה המותאמת לגננות, סייעות וצוות פרא־רפואי, במחשב ובטלפון.

## עדכון מהגרסה 0.4.3 שכבר עובדת אצלך

מאחר שגרסה 0.4.3 כבר עובדת וה־SQL של 0.4.1 כבר הותקן, מבצעים רק את השלבים הבאים:

1. ב־Supabase פתח `SQL Editor`.
2. פתח את הקובץ `supabase/update-v0.5.0.sql`, העתק את כולו והרץ אותו **פעם אחת בלבד**.
3. החלף ב־GitHub את כל קובצי הגרסה הקודמת בכל קובצי 0.5.0.
4. ודא שבתיקיית `api` נשאר רק `index.js`.
5. בצע Commit והמתן ש־Vercel יציג `Ready`.
6. פתח `https://כתובת-האתר/health` וודא שכל הבדיקות ירוקות.

**אין להריץ את `supabase/schema.sql` על המערכת הקיימת.** הוא מיועד רק להתקנה חדשה וריקה.

## משתני Vercel

אין משתנים חדשים ואין צורך ב־Setup נוסף. נשארים רק:

```text
SUPABASE_URL
SUPABASE_PUBLISHABLE_KEY
SUPABASE_SECRET_KEY
```

## מה חדש

- שם אחיד: **מערכת ניהול שיבוצים מעון הדס**.
- עיצוב חדש ונעים לכל מסכי המערכת, עם התאמה מלאה למחשב ולמובייל.
- תיקון כיוון והצגת שעות בכל שדות הזמן ובכל הכרטיסים.
- שיבוץ במצב הכנה וכפתור אחד לפרסום לצוות; אין יותר “זמני/סופי”.
- הצגת כל השינויים לפני פרסום ושמירת גרסאות פרסום.
- תצוגות שבוע מלא, יום והשיבוץ שלי.
- העתקת שבוע קודם עם תצוגה מקדימה ובחירה בין החלפה למיזוג.
- מערכת בקשות חדשה עם סוגי בקשה חזותיים, חיפוש, סינון, סטטוסים ופעולות ברורות.
- הזרמת בקשות לשיבוץ בעסקה אחת, כדי למנוע מצב של שינוי חלקי.
- גננות יכולות ליצור הודעות ומשימות בנוסף ללינור ולאילנית.
- הודעות ומשימות ניתנות לשליחה לכל המעון, לכיתה או לעובדות מסוימות.
- לוח שנה חודשי מלא, מעבר בין חודשים, אירועים על גבי הלוח ופתיחת פרטים.
- ניהול עובדות חדש עם חיפוש, סינון, כרטיסים, שעות, אחוז משרה, תפקידים ואילוצים.
- מסך המסמכים הוסר.
- מסך ראשי נקי ללא הודעת Vercel.
- שיפור מהירות: טעינה מרוכזת, מניעת טעינות כפולות, ניסיון חוזר ועדכון חי.
- המערכת נשארת עם פונקציית Vercel אחת ומתאימה לתוכנית Hobby.
