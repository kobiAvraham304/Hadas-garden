# מערכת ניהול שיבוצים מעון הדס — גרסה 0.16.0

גרסה זו מתקנת את בעיות הגלישה והחיתוך בסלולר ומאחדת את מנוע התאמת העובדים בהוספת שיבוץ ובמציאת מחליף.

## העלאה

1. אין להריץ SQL ב־Supabase. גרסת המסד נשארת `0.12.0`.
2. החליפו ב־GitHub את כל קובצי גרסה `0.15.0` בקובצי `0.16.0`.
3. ודאו שבתיקיית `api` נשאר רק `api/index.js`.
4. בצעו Commit ו־Push והמתינו ל־`Ready` ב־Vercel.
5. פתחו `/health` וודאו:
   - גרסת אתר: `0.16.0`
   - גרסת מסד: `0.12.0`
6. באייפון סגרו את לשונית האתר ופתחו אותה מחדש כדי לנקות CSS ישן מהמטמון.

אין שינוי במשתני הסביבה ואין צורך בתוכנית Vercel Pro.

## עיקרי הגרסה

- חסימה קשיחה של גלישה אופקית ב־Safari ובמסכים צרים.
- כותרת המערכת, פעולות השיבוץ, כרטיסי הימים והניווט התחתון הותאמו מחדש ל־360–390px.
- חלוניות משתמשות במידות של חלון התצוגה ולא במידות של תוכן רחב.
- כותרת החלונית וכפתור הסגירה נשארים גלויים בזמן גלילה במחשב ובטלפון.
- מנוע אחד משותף להוספת עובד ולהחלפת עובד.
- המנוע מחזיר גם עובד פנוי וגם העברה בטוחה מכיתה אחרת, רק אם כיתת המקור נשארת תקינה.
- אותו ציון 1–100, אותן סיבות ואותם כללי סינון בכל נקודות המערכת.
- מטמון קצר משותף לתוצאות ההתאמה מונע קריאות כפולות ומזרז פתיחה חוזרת.
- החלה של המלצה מבוצעת דרך פעולה מאומתת אחת בשרת.

## כללי מנוע ההתאמה

עובד אינו מוצג כמועמד כאשר הוא בחופשה או מחלה מאושרת, נעדר בפועל, חופף לשיבוץ שאי אפשר להעביר, משובץ בכיתה אסורה, אינו מתאים לתפקיד הנדרש, מחוץ לשעות העבודה שלו או יעבור את תקרת השעות השבועית.

עובד מכיתה אחרת מוצג רק כאשר טווח השעות מתאים והעברתו אינה מורידה את כיתת המקור מתחת לתקן ואינה משאירה אותה ללא גננת או מוביל/ה.
