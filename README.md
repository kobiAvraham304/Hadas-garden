# מערכת ניהול שיבוצים מעון הדס — גרסה 0.15.0

גרסה זו מוסיפה מנוע שיבוץ אוטומטי, משדרגת את בחירת העובדים ואת מנוע ההמלצות, ומבצעת התאמה מחודשת של מסכי הסלולר.

## העלאה לגרסה החדשה

1. **אין להריץ SQL ב־Supabase.** גרסת מסד הנתונים נשארת `0.12.0`.
2. החליפו ב־GitHub את כל קובצי גרסה `0.14.0` בקובצי גרסה `0.15.0`.
3. ודאו שבתיקיית `api` נשאר רק הקובץ `api/index.js`.
4. בצעו Commit ו־Push.
5. המתינו ש־Vercel יציג `Ready`.
6. פתחו `/health` וודאו:
   - גרסת אתר: `0.15.0`
   - גרסת מסד נתונים: `0.12.0`

אין צורך לשנות משתני סביבה ואין צורך בתוכנית Vercel Pro.

## שיבוץ אוטומטי

במסך השיבוצים נוסף כפתור **שיבוץ אוטומטי**. לפני שמירת דבר במערכת מוצגת תצוגה מקדימה הכוללת:

- ציון איכות כללי.
- כיסוי התקינה.
- כיסוי גננת או מוביל/ת כיתה.
- התאמה להעדפות העובדים.
- פירוט השיבוץ לכל יום וכיתה.
- נקודות שעדיין דורשות בדיקה.

ניתן לבחור בין:

- **בנייה מחדש** — החלפת טיוטת השבוע בשיבוץ חדש.
- **מילוי חוסרים** — שמירת השיבוצים הקיימים והשלמת החוסרים בלבד.

השיבוץ נשמר כטיוטה בלבד. העובדים יראו אותו רק לאחר לחיצה על **פרסום השיבוץ**.

## לפני שימוש ראשון בשיבוץ האוטומטי

כדי לקבל תוצאה טובה, ודאו שבכרטיסי העובדים מעודכנים:

- תפקיד.
- אופן שיוך וכיתה קבועה.
- ימי עבודה ושעות לכל יום.
- יום חופשי.
- רוטציה או מילוי מקום.
- מקסימום שעות שבועיות.
- העדפות ואיסורי כיתה.
- חופשות ומחלות מאושרות.

## בטיחות השמירה

בעת החלת שיבוץ אוטומטי המערכת מחשבת שוב את התוצאה ומוודאת שהנתונים לא השתנו מאז התצוגה המקדימה. במקרה של כשל בשמירה, המערכת מנסה לשחזר את השיבוץ שהיה קיים לפני הפעולה.
