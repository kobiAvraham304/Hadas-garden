# מערכת ניהול שיבוצים מעון הדס — גרסה 0.9.0

גרסה זו מרחיבה את כרטיס העובד ואת חוקי השיבוץ: מספר ימי חופשה קבועים, שעות שונות לכל יום, תקרת שעות שבועית, רוטציה בין כיתות ותפקידים מדויקים במעון.

## עדכון מהגרסה הפעילה 0.8.0

בגרסה זו **יש עדכון חד־פעמי ל־Supabase**.

1. היכנס ל־Supabase → SQL Editor.
2. פתח את `supabase/update-v0.9.0.sql` והריץ את כולו פעם אחת.
3. אין להריץ מחדש את `schema.sql` על המערכת הפעילה.
4. החלף ב־GitHub את קובצי 0.8.0 בקובצי 0.9.0.
5. ודא שבתיקיית `api` נשאר רק `api/index.js`.
6. בצע Commit ו־Push והמתן ל־`Ready` ב־Vercel.
7. פתח `https://כתובת-האתר/health` וודא שכל הבדיקות ירוקות.
8. באייפון סגור את לשונית האתר ופתח אותה מחדש; במחשב בצע רענון מלא.

אין משתני סביבה חדשים. נשארים רק:

```text
SUPABASE_URL
SUPABASE_PUBLISHABLE_KEY
SUPABASE_SECRET_KEY
```

## מה נוסף

### כרטיס עובד ושעות קבועות

- ניתן להגדיר לכל עובד כמה ימי חופשה קבועים.
- לכל יום ראשון–שישי ניתן לבחור: יום עבודה, יום חופשי או ללא קביעה.
- ביום עבודה אפשר לקבוע שעות התחלה וסיום שונות.
- נוסף שדה `מקסימום שעות שבועיות`.
- חריגה מהמקסימום היא שגיאה חוסמת לפני פרסום השיבוץ.
- שיבוץ ביום חופשי קבוע מוצג כשגיאה.
- שיבוץ מחוץ לשעות הקבועות של אותו יום מוצג כהתראה.

### שיוך לכיתות

- `כיתה קבועה` — העובד משויך לכיתה מסוימת.
- `רוטציה בין כיתות` — ללא כיתה קבועה, מתאים לעובדי השלמה ומילוי מקום.
- `ללא שיבוץ` — לעובדים שאינם משתתפים במערך השיבוצים.
- העדפות הכיתה פושטו: עדיפות, עדיף להימנע או איסור, ללא טווחי תאריך במסך.

### תפקידי המעון

רשימת התפקידים היא כעת סגורה וברורה:

- סייעת
- סייעת מובילה
- סייע
- גננת
- מנהלת מעון
- מזכירה
- אחות

יכולת ההובלה נגזרת מהתפקיד, ולכן אין יותר בחירה נפרדת של “יכול/ה להיות מוביל/ה”. תפקידי עבר נפוצים מומרים בעדכון; תפקיד לא מוכר נשמר ומסומן בכרטיס עד שייבחר לו תפקיד חדש.

### אחות ומזכירה

- אינן מופיעות בבחירת עובדים לשיבוץ.
- יכולות לפרסם הודעות.
- יכולות ליצור משימות.
- יכולות ליצור ולנהל אירועים שהן יצרו בלוח השנה.
- אינן מקבלות הרשאות ניהול עובדים או עריכת שיבוצים.

### מספר גרסה

מספר הגרסה מוצג באופן קטן וקבוע בצד המערכת, גם במחשב וגם בטלפון.
